# AEMS V5 系统设计方案

> 设备管理系统（Airport Equipment Management System）V5 版本  
> 更新日期：2026-03-31  
> 技术栈：Vue 3 + Element Plus + ECharts + Vue Router + Pinia

---

## 1. 项目概述

AEMS V5 是面向企业设备管理部门的设备全生命周期管理系统，覆盖设备台账、软件管理、工单处理、维护计划、备件库存、机房管理、文档管理和统计报表等核心业务。

### 1.1 V5 核心特性

- **响应式布局**：支持桌面端和移动端自适应
- **树+表格联动**：设备/软件/备件/文档模块均支持左侧分类树+右侧数据表
- **健康度评分**：设备健康度四维度量化评估（状态40%、故障频次30%、寿命15%、维护及时15%）
- **工单向导**：4步骤引导式工单创建流程
- **SLA 监控**：工单 SLA 响应/修复时限可视化计时
- **库存预警**：备件库存不足/偏低/积压三级预警

## 6. 技术特性

### 6.1 UI 组件使用

| 组件 | 使用场景 |
|------|----------|
| el-table + el-table-column | 所有列表页数据表格 |
| el-tree | 设备/软件/备件/文档分类树 |
| el-descriptions | 详情页信息展示 |
| el-tabs | 多标签页（设备详情/统计/出入库） |
| el-steps | 工单创建向导 |
| el-timeline | 工单操作日志 |
| el-progress | 机柜使用率 |
| el-pagination | 列表分页 |
| el-dialog | 新增/编辑弹窗 |
| el-form + el-form-item + rules | 所有表单验证 |
| ECharts | 仪表盘、饼图、折线图、柱状图、环形图 |

### 6.2 交互设计

- **树形联动**：左侧树点击自动筛选右侧数据
- **树可隐藏**：所有树+表格页面支持折叠树面板
- **行内操作**：表格操作列支持下拉菜单（更多）
- **状态着色**：Tag 组件按状态自动映射颜色
- **溢出提示**：长文本列使用 show-overflow-tooltip
- **行样式**：库存预警表格按预警级别着色行背景
- **图表联动**：仪表盘和统计页图表支持日期范围筛选

### 6.3 响应式布局

- 仪表盘指标卡：xs=12, sm=12, md=6（手机2列，桌面4列）
- 健康度卡片：span=6（桌面4列）
- 图表网格：span=12（桌面2列）
- 弹窗宽度：500px-900px 不等
